# Foundly Backend

The backend is a FastAPI REST API with asynchronous SQLAlchemy, PostgreSQL, and Alembic migrations. It uses uv for dependency and environment management.

## Requirements

- Python 3.9 or newer
- uv
- PostgreSQL 15 or newer

## Technology stack

**Runtime dependencies**

- FastAPI
- Uvicorn
- SQLAlchemy with asyncio
- asyncpg
- Alembic
- Pydantic and pydantic-settings
- pwdlib with Argon2
- PyJWT
- python-multipart

**Development dependencies**

- pytest and pytest-asyncio
- httpx
- aiosqlite
- Ruff

## Getting started

```bash
cd backend
cp .env.example .env
uv sync
```

Copy `.env.example` to `.env` and update `DATABASE_URL` and `SECRET_KEY` for your environment. Do not commit `.env`.

## Database setup

Create a local PostgreSQL database:

```bash
createdb foundly
```

The default connection string is:

```text
postgresql+asyncpg://postgres:postgres@localhost:5432/foundly
```

Update `DATABASE_URL` in `.env` if your username, password, host, port, or database name differs.

## Migrations

Alembic configuration is available in `alembic.ini`, with migrations stored in `alembic/`. The migration environment and first revision will be added together with the SQLAlchemy models.

Once models and the Alembic environment are in place, use:

```bash
# Create a migration after changing models
uv run alembic revision --autogenerate -m "describe the change"

# Apply pending migrations
uv run alembic upgrade head

# Roll back the latest migration
uv run alembic downgrade -1
```

Always review autogenerated migrations before applying them.

## Development

```bash
uv run fastapi dev app/main.py
```

The API will be available at `http://localhost:8000`, with interactive documentation at `http://localhost:8000/docs`.

The FastAPI entry point (`app/main.py`) will be added when application features are implemented.

## Testing and linting

```bash
uv run pytest
uv run ruff check .
uv run ruff format .
```

## uv commands

```bash
uv sync              # Install runtime and development dependencies
uv add <package>     # Add a runtime dependency
uv add --dev <package> # Add a development dependency
uv lock              # Update the lockfile
uv run <command>     # Run a command inside the project environment
```

## Project structure

```text
app/
├── core/           Configuration, security, and shared infrastructure
├── database/       Database engine and session management
├── models/         SQLAlchemy models
├── schemas/        Pydantic request and response schemas
├── routers/        FastAPI route handlers
├── services/       Business logic
└── dependencies/   Reusable FastAPI dependencies

alembic/            Database migrations
tests/              Automated tests
```

Routers should stay thin, with business logic in `services/`. Database access and schema definitions belong in `database/`, `models/`, and `schemas/`.
